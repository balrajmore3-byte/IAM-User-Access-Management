# IAM User Access Management System

## Project Overview
A beginner Identity and Access Management (IAM)
project that simulates user account management,
role-based access control, and access reviews.

## Objectives
- Maintain a sample employee identity inventory
- Check access using role-based permissions
- Deactivate inactive or departing users
- Identify accounts requiring access review
- Record actions in an audit log

## Technologies
- Python
- CSV
- Git and GitHub

## IAM Concepts
- Identity lifecycle management
- Role-Based Access Control (RBAC)
- Authentication vs. authorization
- Access governance
- Least privilege
- Audit logging

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run: python main.py

## Limitations
This is a learning prototype using local CSV files.
It is not intended for real employee accounts or
production access enforcement.
